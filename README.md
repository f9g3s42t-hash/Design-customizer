# 🎨 JavaScript Design Customizer

A simple and interactive web application built with **HTML, CSS, and JavaScript** that allows users to dynamically customize heading texts, colors, font weights, font sizes, borders, and background colors using input fields and an apply button. It also includes a reset feature to restore default styles.

## 🚀 Features
- **Dynamic Styling:** Change heading text, text color, font weight, and font size instantly.
- **Container Customization:** Modify container background color and border styles.
- **Action & Reset Buttons:** Apply changes with a single click or reset everything back to default.
- **Clean UI:** Styled using modern CSS Flexbox and gradients.

## 🛠️ Technologies Used
- **HTML5**
- **CSS3 (Flexbox, Transitions)**
- **JavaScript (DOM Manipulation, Event Listeners)**
